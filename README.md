# 投递包 · applypack

> 面向中国校招生的简历生成与网申自动填充工具。
> **一份档案，投遍所有网申。**

## 先说最值钱的七句话

1. 你的简历数据从不离开浏览器 —— 打开 Network 面板，你可以自己验证。
2. 筛选是全确定性的，你能看到每一段经历**为什么**被选中或淘汰。
3. 润色层带硬校验：任何原文里找不到的数字，都会被拒绝并重写。
4. 填表用你自己的浏览器、由你逐项确认；服务端不代替你做任何操作。
5. 忘记口令数据就没了 —— 这是真端到端加密的代价，我们选择接受。
6. 中英双版简历与自我介绍出自同一份档案，数字集合必须完全相等 —— 我们机械校验这一点。
7. **本项目不代为提交。** 提交前你会看到一份逐项摘要，确认之后由你自己点下提交按钮。

## 功能一览

- **档案管理**：一份结构化档案（schema 严格校验、schemaVersion 迁移），AES-GCM + PBKDF2 端到端加密，密文落盘、口令不出浏览器。
- **JD 匹配**：全确定性打分，逐条给出「为什么选中 / 为什么淘汰」及分数构成。
- **简历渲染**：中文单栏 / 英文校招版 / ATS 纯文本，中英出自同一事实源，数字集合机械校验相等。
- **自我介绍三视图**：`intro_zh@60s` / `intro_en@60s` / `intro_en@200w` 共用同一事实源，字数落在档位 ±10% 内、句均可朗读、数字必须能在简历上找到。
- **网申辅助**：北森 / Moka / 大易三家适配器 + 启发式兜底；逐项预览确认后才写入；缺口语义分五类（不匹配 / 无值 / 歧义 / 被挤出 / 选项不符）；上传槽位提示建议文件名（中 / 英 / 双语版）；提交前审核摘要区分「自动填的」与「启发式猜的」，只拦一次；提交后手填字段可回写档案（冲突不自动覆盖）。

## 本地开发

```bash
pnpm install
pnpm test        # 单测（turbo 并行）
pnpm typecheck   # 类型检查 —— 也是「零 DOM」等约束的执行手段
pnpm build       # 全量构建（web 产物在 packages/web/dist/）
```

需要 Node ≥ 22 与 pnpm 12。

## 适配器与快照维护

自动填充按「**适配器优先，启发式兜底**」工作（DESIGN ADR-7）：命中已知平台用人工核对过的精确选择器，没命中或选择器扑空（平台改版）则逐字段降级回启发式——降级是静默的，字段照常走匹配流程。

**当前支持的平台（前 3 个）：**

| 平台 | DOM 特征 | 适配器解决的问题 |
|---|---|---|
| 北森 | 控件 id 是部署期随机串，字段标题是普通 `span`（非 `label`） | 标题对提取层不可见，「姓名 / 姓名拼音」靠 placeholder 打平成歧义，必须精确钉 |
| Moka | label 关联规范，语义在 `data-moka-field` 属性上 | 平台越规范启发式越够用——适配器只钉少数高危字段，其余放给启发式 |
| 大易 | `p_*` 稳定 name；select 的 value 常是中文；毕业时间只有年份下拉 | 「紧急联系人电话」与「手机号码」得分打平，钉 `p_mobile` 解围；年份下拉与档案 `YYYY-MM` 的缝走缺口提示，不硬猜 |

**为什么是这三家**：国内校招网申的表单层基本被这三家 ATS SaaS 覆盖（外企在华校招的申请页也大多跑在它们上），且三家的 DOM 难度恰好构成三个典型档位，放在一起做才能互相印证适配器边界画在哪。

**快照维护约定**：

- 每个适配器对应一份版本化快照 fixture（`packages/extension/src/fill/__fixtures__/snapshot-*.ts`），当前为**手工建模的近似**（provisional）——结构特征按真实页面对照公开资料建模，不是逐字节拷贝。
- `PlatformAdapter.version` 必须与快照上的 `data-platform-version` 相等，且每个选择器都要在自家快照上解析成功——这两条由 CI 断言钉死。平台改版时：重新采集快照 → 校对选择器 → **两边一起 bump 版本号**，只改一边会直接红灯。

## 三条设计原则

1. **零后端。** 多用户隔离不是被"实现"的，而是被"取消"的 —— 没有服务端就没有多租户，隐私从架构承诺变成可自证的事实。
2. **验收不交给模型。** 简历最致命的错误是编造。LLM 输出的每一个数字都必须在原文中找得到，否则拒绝重写。这一层是确定性代码。
3. **不代提交。** 本项目只做填表辅助和提交前提示，提交按钮永远由你自己点。

## 已知限制

- **忘记口令，数据就没了。** 这是真端到端加密的代价，无法通过重置密码找回 —— 请务必导出加密备份。我们不会（也无法）替你保存任何后门。
- 无跨设备同步：数据在各自浏览器里。
- 需要自备模型 API Key（BYOK）。
- 英文 60 秒自我介绍档在素材较轻的档案上会**诚实报缺**（填不满档位就如实标红）——我们不用调语速常数的方式把它藏起来，见 `packages/core/src/intro/targets.ts` 的拍板注记。
